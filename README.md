# Retail Sales Analysis - SQL Server Project

## Project Overview

This project analyzes retail sales data using **Microsoft SQL Server** and **SQL Server Management Studio (SSMS)**.

The project focuses on customer purchases, product sales, revenue generation, and overall business performance using SQL queries and database features.

## Objectives

* Analyze customer purchasing behavior
* Identify top-selling products
* Analyze sales and revenue performance
* Identify high-value customers
* Rank customers and products
* Practice advanced SQL Server concepts
* Build reusable database objects such as views and stored procedures

## Tools Used

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)
* SQL
